Full-Stack-AI-Interview-Simulator

Language used: JavaScript, Tailwind

Developed a full-stack AI interview simulator that utilizes the Gemini AI API to generate tailored interview questions based on job titles, reducing manual preparation time by 90%. Integrated React Hook for speech-to-text, allowing spoken answers to be transcribed with 95% accuracy and stored in PostgreSQL via React and Node.js. Built a user-friendly front end with Next.js, TailwindCSS, and ShadCN components, improving UI consistency and reducing development time by 20%. Implemented a feedback and redo system for past interviews using PostgreSQL, boosting user confidence by 50%.
